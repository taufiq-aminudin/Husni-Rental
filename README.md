# HUSNI RENTAL EXCAVATOR

Website landing page profesional untuk HUSNI RENTAL EXCAVATOR — Paringin/Tanjung, Balangan, Kalimantan Selatan.

## Fitur
- Responsive desktop & mobile
- Hero section
- Layanan rental harian, borongan, bulanan
- Proyek kolam, land clearing, kebun sawit
- Area pelayanan
- Tombol WhatsApp dengan pesan otomatis
- SEO dasar
- Siap deploy ke GitHub Pages

## Menjalankan
Cukup buka `index.html` di browser.

## GitHub Pages
1. Buat repository baru, misalnya `husni-rental-excavator`.
2. Upload semua file dan folder dari project ini.
3. Masuk ke **Settings → Pages**.
4. Pada **Build and deployment**, pilih **Deploy from a branch**.
5. Pilih branch `main` dan folder `/ (root)`.
6. Simpan. GitHub akan memberikan alamat website Pages.

Nomor WhatsApp yang digunakan: `081250434900`.

> Foto hero menggunakan gambar dari Unsplash melalui URL eksternal. Jika ingin website 100% mandiri, ganti URL foto pada `assets/css/style.css` dengan foto excavator milik sendiri.
